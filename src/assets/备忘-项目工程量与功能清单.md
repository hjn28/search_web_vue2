## 五、数据流图

```
用户操作
  │
  ├─ 聚类搜索 → searchZFSearch2 → 右侧表格展示
  │
  ├─ 生成摘要 → searchZFZhaiyao(type=1) → 异步任务 → 任务完成 → handleZhaiyaoResult → 摘要展示
  │
  ├─ 生成综述 → searchZFZhaiyao(type=2/3) → 异步任务 → 任务完成 → renderZsbgTree
  │   │
  │   ├─ extractTreeFromPayload → cloneTree
  │   ├─ load(localStorage edits) → applyEditsToTree
  │   └─ flattenTree → zsbgRenderNodes → 模板渲染
  │       │
  │       └─ 编辑模式 → blur → updateTreeField + setFieldValue → flattenTree 重渲染
  │
  ├─ 导出综述 → DataExporter.exportOverviewReport
  │   └─ captureChartImage (ECharts screenshot)
  │
  └─ 导出摘要 → DataExporter.exportSummaryDoc
```

### 6.2 待办/已知问题

- [ ] 编辑模式下光标位置在 Vue 重渲染后可能会重置
- [ ] 图表截图在 DOM 不可见时可能失败
- [ ] 综述导出 Word 的图表分辨率还需优化

### 6.3 关键技术决策

1. **编辑采用"原始数据 + 增量 edits"模式**（而非存储完整 HTML），保证 edits 可适配最新 API 数据
2. **contenteditable + blur** 方案而非富文本编辑器（TinyMCE/Quill），保持轻量
3. **展示层加粗**而非存储层加粗，编辑时自动丢弃 HTML 标签，重渲染自动重新加粗
4. **树扁平化渲染**方式，将树结构转为顺序节点数组，用 `v-for` 逐一渲染
